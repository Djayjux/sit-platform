# SIT - From Seed to Art

A complete latte art practice platform with fluid simulation, coffee academy, and recipe library.

## Features
- Realistic milk pouring simulation with brush, flow, and cup tilt controls
- 12 guided patterns with difficulty ratings
- 7-chapter Coffee Academy (farm to cup)
- Beyond the Cup: culinary, beauty, home, and creative coffee uses
- Scoring system with detailed breakdown
- Pro access code system via Google Sheets
- Works offline, no server required

## Hosting
This is a static site hosted on GitHub Pages.

## Admin
Pro codes are managed through Google Sheets.
